# Event posters

Drop a square image here named after the event slug and it replaces the
generated gradient cover automatically — no code change. A missing file
falls back to the gradient, so partial coverage is fine.

- Format: PNG (or set `Event.poster` for another extension)
- Shape: square; rendered at 86px in lists and 400px in the detail panel
- Suggested source: 800x800 or larger
